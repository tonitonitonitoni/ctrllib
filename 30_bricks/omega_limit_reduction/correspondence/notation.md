# Notation correspondence

Lean infDist is rendered as $\operatorname{dist}(x,S)$. StableRelativeTo and
AttractiveRelativeTo are rendered as relative stability and attraction of a
target set under the supplied flow.

Omega-limit notation means accumulation along times tending to infinity.
Dimension: metric state space E, with finite-dimensional assumptions only at selected endpoints. Type: Flow, target Set E, and real infimum distance. Frame: no physical frame is assumed. Sign: infimum distance is nonnegative and converges to zero. Unit: abstract distance units. Lean: StableSet and AttractiveSet define the exact types.
