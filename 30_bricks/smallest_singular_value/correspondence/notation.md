# Notation correspondence

| Object | Type, dimension, frame, sign, and unit convention |
| --- | --- |
| Matrix and vector | Exact finite-dimensional real or ring types in the canonical Lean declaration |
| Quadratic, singular-value, or rank quantity | The named definition and determinant/inner-product convention in the module |
| Frame | Coordinate frame is abstract unless an application interface supplies one |
| Sign and unit | Algebraic signs and unit-free scalar conventions follow Lean; physical units are external |

Lean declarations are authoritative for coercions and dimensions.
