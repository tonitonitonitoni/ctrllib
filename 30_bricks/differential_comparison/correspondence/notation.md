# Notation correspondence

`v`, `v'`, and `ε` are real-valued time functions. `V` is a scalar function on
a normed state space, `f` is a vector field, and `x` is a trajectory. `a` is a
decay rate; `c` or `M` bounds a disturbance. All frame, unit, and model
correspondence remains external.
Dimension: scalar comparison value and finite-dimensional state where a sandwich is used. Type: real-valued trajectory and Euclidean state. Frame: no physical frame is present. Sign: the rate is positive where convergence is claimed and values are nonnegative when required. Unit: abstract Lyapunov-value units. Lean: LyapunovDecrease and QuadSandwich carry the exact types.
