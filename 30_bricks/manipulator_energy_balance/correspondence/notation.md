# Notation correspondence

| Object | Type, dimension, frame, sign, and unit |
| --- | --- |
| State, matrix, or trajectory | Exact finite-dimensional type in the canonical Lean declaration |
| Derivative, energy, or dissipation | Named canonical definition and sign convention |
| Frame | Abstract frame unless an application interface supplies one |
| Unit | Algebraic/unit-free convention; physical units remain external |

Lean is authoritative for dimensions and coercions.
