# Notation correspondence

| Conventional symbol | Lean interface |
| --- | --- |
| J | Type: square lower-right block, 6 by 6 in the Euclidean endpoint |
| Gamma | Type: nested coordinated matrix, 12 by 12 in the Euclidean endpoint |
| det | Unitless algebraic determinant over the declared coefficient ring |
| sigmaMin | Scalar singular-value map supplied through hsvd |
| frame | Rot is the base-to-CoM rotation block; frame semantics are external |
| sign | Zero lower-left blocks and positive determinant criterion use the declared signs |

Dimensions and coercions are authoritative in the Lean declarations.
